# 🏕️ DNP Camping Tracker (ระบบตรวจสอบวันว่างพื้นที่กางเต็นท์)

ระบบตรวจสอบและเฝ้าระวังวันว่างพื้นที่กางเต็นท์ อุทยานแห่งชาติ (กรมอุทยานแห่งชาติ สัตว์ป่า และพันธุ์พืช — DNP) แบบ Real-time อัปเดตข้อมูลอัตโนมัติทุก 1 นาที

---

## 🌟 จุดเด่น
- **กรองเฉพาะวันว่าง**: ซ่อนวันที่เต็มอัตโนมัติ แสดงเฉพาะวันที่มีที่ว่าง
- **อัปเดตทุก 1 นาที**: ดึงข้อมูลล่าสุดจาก `nps.dnp.go.th` แบบอัตโนมัติ
- **ตารางอ่านง่าย**: ชัดเจน ไม่มีลูกเล่นรกรุงรัง
- **ตารางแถบรายวัน**: เทียบรายวัน 1-31 แบบเดียวกับหน้าเว็บ DNP
- **แจ้งเตือนคิวหลุด**: ตรวจจับและแจ้งเตือนทันทีเมื่อมีคนยกเลิกทำให้มีที่ว่างเพิ่มขึ้น

## 🚀 วิธี Deploy ขึ้น Cloud ฟรี (Render.com)

1. นำโค้ดโปรเจกต์นี้ขึ้น GitHub Repository
2. เข้าเว็บ [https://render.com](https://render.com) แล้ว Login ด้วย GitHub
3. กดปุ่ม **"New +"** -> เลือก **"Web Service"**
4. เลือก Repository ที่เพิ่งสร้างขึ้นมา
5. ตั้งค่า (หรือระบบจะอ่านจาก `render.yaml` ให้อัตโนมัติ):
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
6. กด **"Create Web Service"**
7. รอระบบ Build ประมาณ 1-2 นาที จะได้รับ URL สาธารณะ เช่น:
   `https://dnp-camping-tracker.onrender.com`
   สามารถเปิดดูบนโทรศัพท์มือถือ หรือแชร์ให้เพื่อนๆ ใช้งานได้ตลอด 24 ชั่วโมง
